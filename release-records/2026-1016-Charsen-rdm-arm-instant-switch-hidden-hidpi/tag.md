# RDM-ARM 1.0.5 —— 选中即切换，补回隐藏 HiDPI

状态：**双源已发布**。`origin`（Gitee）与 `github` 的分支、tag、Release 与附件一致。

## 起因

三条试用反馈，都是「别把交互搞复杂」：

1. **选完分辨率画面会黑一下，还弹确认框** —— 「不需要确认，直接显示变化结果」；
2. 偏好设置里的「快捷键」没人用；
3. 菜单里的「恢复已记住的模式 / 忘记已记住的模式」也不需要。

外加上一轮的另一条：**刷新率菜单在只有一档时整块消失**，操作者会以为功能坏了。

同时纠正一个我先前判断错的结论：曾按「面板 2560 像素 ÷ 2」推出「HiDPI 上限就是
1280」。实测 macOS 会生成**超采样** HiDPI —— 2560 × 1600 的面板上，1920 × 1200 的
HiDPI 用 3840 × 2400 渲染再缩回面板 —— 只是**不通过公开接口返回**。这正是老用户
觉得「原版 RDM 能列出来、这个版本列不出来」的原因。

## 改了什么

| 位置 | 变化 |
| --- | --- |
| 切换 | 去掉切换后的 15 秒确认框与自动还原，**选中即生效** |
| 偏好设置 | 去掉「快捷键」标签页（4 个减到 3 个）；去掉「切换后要求确认」开关 |
| 菜单 | 去掉「记住 / 忘记 / 恢复已记住的模式」三项（自动记忆保留） |
| 源码删除 | `HotKeyCenter.swift`、`HotKeyAction.swift`、`ModeChangeGuard.swift` |
| 源码新增 | `Sources/Optional/PrivateModeTable.swift`（私有模式表） |
| 模式列表 | 并入 macOS 不公开的超采样 HiDPI；原生分辨率判定排除它们 |
| 刷新率菜单 | 只有一档时也显示并把那一档打勾，不再整个隐藏 |
| 默认值 | 只列 HiDPI（原本如此）+ 不列 macOS 标记为不可用的模式（改默认） |

`chore(release)` 只改 3 个版本号。

## 关于「隐藏 HiDPI」——这版最大的变化

macOS 生成的模式比它对公开 API 承认的更多。把私有模式表按原版 RDM 的偏移读出来，
与公开枚举逐条按 mode ID 比对：

| 显示器 | 公开枚举 | 私有表 | 私有独有 |
| --- | --- | --- | --- |
| 一台 4K 屏 | 257 | 290 | 33 个，全是 2× |
| 一台 2560 × 1600 便携屏 | 46 | 55 | 9 个，全是 2×（含 1920 × 1200、2048 × 1280、2560 × 1600） |

偏移植信前先自检：`mode` / `width` / `height` / `density` 四个字段用 303 个模式与公开
API 逐条核对，**0 处不符**；`depth` 与 `refreshRate` 在 macOS 27 上读出的是垃圾值，
因此**完全不读**。解码失败比例超过阈值就整体停用，退回纯公开模式。

应用侧实测：经应用自身的命令行路径切到 `1920 × 1200 ⚡️`（背板 3840 × 2400）成功，
随后还原。这批模式与旋转、亮度共用同一个可选开关，关掉即回到纯公开 API。

## 什么没受影响

- **每屏模式记忆照旧自动工作**：换过的分辨率仍按屏记住，重插后自动恢复。去掉的只是
  菜单里的三个手动项。
- 旋转、亮度、分辨率 / 刷新率两段式菜单、去重与排序逻辑均未改动（刷新率菜单只是
  不再隐藏自己）。
- 命令行 `-w/-h/-s/-r/-d/-lm/-ld/--json/--rotation` 全部保留。

### 未验证 / 已知代价

- **私有表的刷新率拿不到**（该字段已失效），隐藏模式沿用同尺寸公开模式的刷新率。
- 只在本机（一台 4K + 一台 2560 × 1600 便携屏，macOS 27 / arm64）实测；无 Intel 机器
  与旧系统实机验证，仅保证通用二进制两切片都存在。

## 遗留

- **私有模式表的偏移随系统升级可能再变**。已做自检与整体降级，但下次系统大版本升级
  值得重跑一次 `--selftest` 看隐藏模式数是否为 0（为 0 即代表自检已停用）。
- 7 条长期未使用的本地化键：`app.name`、`menu.builtIn`、`menu.currentResolution`、
  `menu.unsupported`、`menu.autoApplied`、`settings.launchAtLogin`(+`.hint`)。
  注意 `rotation.*` 与 `lang.system` 是动态拼键 / 内部使用，别误删。
- 仍未做：零单元测试、无 `LICENSE`、无 `CHANGELOG`。
- 命令行 `-lm` 仍默认列全部模式（未跟着改成默认只列 HiDPI），保留原行为。
